## 4. 데이터 처리 흐름

```
D1·D2·D3 엑셀 + D4 API ──► build_clean_db.py ──► food_nutrition (352,071건)
D5 원시자료 ──────────────► build_clean_db.py ──► knhanes_2024_adult (6,033명) ──► train_risk_models.py ──► 위험 모델 3종
D6 국민건강통계 ──────────► extract_population_baseline.py ──► population_baseline (660)
D7 KDRI PDF ──────────────► build_kdri_table.py ──► ref_kdri_adult
문헌 ──────────────────────► build_reference_tables.py / build_effects_table.py ──► ref_*
food_nutrition ───────────► build_food_mapping.py ──► food_group_stats, food_alias
                                 └► make_runtime_bundle.py ──► 배포용 runtime.db (D5 제외)
```

## 5. 검증 결과 요약

- 정제한 국민건강영양조사 가중 유병률이 공식 통계와 일치: 고혈압 30.7%, 당뇨 14.8%, 고콜레스테롤 30.2%, 비만 37.9%, 고위험음주 12.7% (흡연 16.1% vs 공식 15.9%)
- KDRI 에너지 공식: PDF 산출값 6개를 1 kcal 단위까지 재현
- 위험 모델 5겹 교차검증 AUC: 고혈압 0.831, 당뇨 0.789, 고콜레스테롤 0.744
- 엔진 테스트 15건 통과 (`python -m unittest discover tests`)
